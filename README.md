# 민법 OX 퀴즈

주차별 민법 OX 문제를 풀고, O/X를 누르면 바로 정답 여부와 해설이 나오는 퀴즈 사이트입니다.

- 사이트: https://claude.ai/artifact/63ph2tFDxMt3iktyF9AcBi
- 소스: `site/civil-law-ox.html`

## 사용법
- **문제 풀기**: 주차를 고르고 ○/× 를 누르면 정답·오답과 해설, 근거 조문이 바로 표시됩니다. 푼 기록은 각자 브라우저에 저장됩니다.
- **문제 관리** (페이지 소유자에게만 보임): 주차, 주차 주제, 문제, 정답(O/X), 해설, 근거 조문을 입력하고 **저장하고 게시**를 누르면 링크를 가진 모든 사람에게 반영됩니다.
