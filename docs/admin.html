GitHub 연결

문제를 사이트에 저장하려면 이 저장소에 쓸 수 있는 GitHub 토큰이 필요해요. 한 번 입력하면 이 브라우저에 기억돼요.

토큰 만드는 방법
  1. GitHub 토큰 만들기 페이지를 열어요.
  2. Token name에 아무 이름(예: 민법 OX)을 적고, Expiration(만료일)을 정해요.
  3. Repository access에서 Only select repositories → -OX- 저장소를 골라요.
  4. Permissions → Repository permissions → Contents를 Read and write로 바꿔요.
  5. Generate token을 누르고 나온 토큰을 복사해 위 칸에 붙여 넣어요.
